## 📊 Project Specifications

### Technology Stack
- **Framework**: React 19.2
- **Language**: TypeScript 7.0
- **Build Tool**: Vite 8.2
- **Testing**: Vitest 4.1 + React Testing Library 16.3
- **Deployment**: Vercel (serverless)
- **Accessibility**: WCAG 2.1 AA compliant

### Application Features
- **6-Stage Workflow**: Observable evidence chain from discovery to verification
- **Role-Based Perspectives**: Auditor → Facilities → Verifier simulation
- **Persistent State**: LocalStorage-based, survives page refresh
- **Accessibility**: Text sizing, high contrast, reduced motion support
- **Responsive**: Mobile-first design (320px to 1440px+)
- **Demo Data**: Fully fictional, for presentation purposes

### Deployment Details
- **Platform**: Vercel (https://vercel.com)
- **URL**: https://011-access-haryana-campus.vercel.app
- **Build Time**: ~3 minutes

  - Total bundle: ~84 kB gzipped
- **Browser Support**: Chrome 90+, Firefox 88+, Safari 14+
